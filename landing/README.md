# BioPulse landing (local draft)

Standalone Spanish acquisition page for the BioPulse iOS app. It uses only HTML, CSS and browser JavaScript; it has no tracking, backend, email collection or external write path.

## Preview

From the repository root:

```powershell
python -m http.server 4173
```

Open `http://127.0.0.1:4173/landing/`.

The page intentionally says beta access is coming soon. Configure the destination, consent copy, support contact, final privacy policy and App Store URL before enabling signups or launch CTAs. It does not claim ML is validated, cloud sync is live in iOS, or that the app is available in the App Store.
